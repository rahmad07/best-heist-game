A top-down heist game for the [make.fun best heist game bounty](https://make.fun/bounty/best-heist-game-20261122-0559). You are a thief crossing a guarded gallery: slip past patrolling guards and their vision cones, dodge the sweeping security cameras, grab the loot, and reach the getaway before the alarm meter peaks.

Played with keyboard and mouse in a desktop browser; static files only, no network requests.

Play it: serve `game/` with any static HTTP server and open `game/index.html` (or run `node serve.ts` and open http://localhost:8080).

## Controls

- **WASD / arrow keys** — move the thief
- **Mouse** — look / interact
- **Shift** — sneak (slower, quieter)
- **E** — grab loot / use tools
